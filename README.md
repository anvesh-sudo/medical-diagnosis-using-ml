# 🏥 Medical Diagnosis Using Machine Learning

## 📌 Overview
This project uses Machine Learning algorithms to predict medical diseases such as
**Diabetes, Heart Disease, and Parkinson’s Disease** based on patient data.

---

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 🧠 Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

---

## 🔄 Project Workflow
1. Data Collection
2. Data Preprocessing
3. Feature Selection
4. Model Training
5. Model Evaluation
6. Disease Prediction

---

## 🎯 Objective
To assist early disease detection using machine learning techniques.
